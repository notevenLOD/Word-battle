# 标点坦克 · Word 摸鱼版

一个伪装成 Word 文档的坦克大战小游戏。

整篇英文论文铺满 A4 横向页面，目前已准备 6 篇不同的论文作为轮换地图。敌方是会移动的逗号、问号、感叹号、分号、长句、方括号、会弹跳的邮件符 `@`、比较符号 `<`，偶尔出现的金色稀有格式符，以及会变成红色的精英标点。自机是一只 Windows 风格的鼠标指针箭头，箭头右下方旋转的圆圈加载条就是生命值；每损失一格血量，就少一段蓝色圆弧。高亮掩体会按每张地图的固定版面布置，每一道荧光笔都压在指定的文字行上。子弹、火箭、激光、爆炸和击杀飘字都由文档里的标点、墨点与修订痕迹构成。老板从远处看过来，只会看到一篇正在被校对的英文论文，以及缓慢增加的词数。

## 运行

直接双击 `index.html` 即可，无需安装依赖或联网。

如果想用本地服务器：

```powershell
# 在 word-tank 目录下任选一种
python -m http.server 8000
# 然后打开 http://127.0.0.1:8000/
```

## 文本与背景图导出

- `game-texts.txt`：集中整理 Word 界面、游戏 HUD、奖励卡池、敌人/首领、动态提示、六张文章的完整文本，便于手动搜索和改写。
- `backgrounds/clean/`：六张 2240 × 1584 的干净背景文档图片，已移除 Canvas、自机、敌人和游戏 HUD。
- `backgrounds/grid/`：同一组页面，叠加 50/100 像素坐标网格、竞技场红框和坐标数字，便于定位和修改障碍物。
- `backgrounds/manifest.txt`：页面坐标、竞技场范围、六张地图的障碍档案与文件索引。
- `backgrounds/contact-sheet.png`：六张背景文档的总览图。
- 这些导出文件不会自动同步回游戏；真正生效的文本仍在 `index.html` / `game.js` 中。

## 操作

移动和开火完全使用键盘，不需要鼠标瞄准。

| 按键 | 动作 |
| --- | --- |
| `W` `A` `S` `D` | 上 / 左 / 下 / 右移动 |
| `I` `J` `K` `L` | 上 / 左 / 下 / 右四向开火 |
| `P` / `Esc` | 暂停 |
| `B` | 一键切换到阅读视图（老板键） |
| `1` `2` `3` | 在“格式”奖励窗口选择对应选项 |
| `M` | 静音 / 开启音效 |
| `R` | 游戏结束后重新开始 |
| `F2` | 打开 / 关闭测试控制台 |

按住任意方向的开火键可以连续射击；同时按住多个时，以最后按下的方向为准。普通敌机和方括号 Boss 的子弹只沿上下左右或端口方向飞行；自机默认朝四向开火，拿到蓝色“注意分散”后会额外向左右各偏 30° 射击。再次拿到“注意分散”会继续在最大角度外各加一条弹道。它是独立的弹道层，不会因为切换到激光、火箭或三叉而丢失。

开局后系统鼠标指针会在文档页内隐藏，画布中的箭头才是自机，不需要也不响应鼠标操作。

### 新手教程

游戏开始前会进入六页动画教程：

1. WASD 移动
2. IJKL 四向校对射击
3. 右侧蓝色生命环
4. 黄色格式碎片与蓝色回血权限
5. 格式奖励选择
6. 最终目标与“开始校对”按钮

第 1–5 页右上角都有“跳过教程”，点击后直接进入第 6 页。第 2–5 页提供“上一页”；按 Enter 或点击“下一页”继续。教程窗口长宽各为原尺寸的 50%，背景界面保持清晰、不做模糊处理。页内鼠标指针和生命环沿用游戏内的实际绘制样式；第 2 页严格按 I→J→K→L 的高亮顺序逐向发射，命中后播放击破效果并移除敌机。

## 出怪与格式奖励

- 红色竞技场边框外固定有 **12 个出怪点**：上、下、左、右各 3 个。敌人先出现在红框外，再走进红框内；每次出怪从这 12 个位置中随机选择。
- 每四轮是一个 Boss 波。每关的首领从“长句”、方括号二重奏、弹跳邮件符 `@` 和比较符号 `<` 中随机轮换（不会连续重复同一种）。清空 Boss 波后，上方会浮出一个 Word 风格的“格式”悬浮窗，给出 3 个随机格式选项。游戏暂停，按 `1` / `2` / `3` 或直接点击条目选择；奖励立即写入当前这一局。
- 奖励出现时，后方文档、文字行和荧光笔障碍都会完全静止，不会震动；直到选择完毕才会继续。

### 稀有度

白、蓝、红三档。单槽的基础权重为 **白 55% / 蓝 30% / 红 15%**，并且普通轮次中**必定至少有一个蓝色选项**；若随机结果没有蓝色，会把其中一个白色（必要时红色）替换成蓝色。获得“格式繁多”后，选项数从 3 个增加到 4 个。

| 稀有度 | 格式 |
| --- | --- |
| 白色 · 普通 | 射速 +30%；移速 +50%；背面盾宽 +半格；修正力度 +1；死而后生；修订光环 |
| 蓝色 · 精良 | 射速 +60%；移速 +100%；全宽背面盾；60° 散射弹道；急速修改；2 颗大型环绕脚注；修正力度 +2；白日梦 |
| 红色 · 稀有 | 射速 +100%；每次射击 +1 发平行子弹；贯穿激光；火箭校对；三叉；格式繁多；修正力度 +3；愈战愈勇；信心爆棚；蓝海 |

### 可重复叠加

- **射速 / 移速 / 背面盾 / 环绕脚注 / 子弹数量 / 修正力度**都可以反复选取。
- **背面盾**：白色每次增加半个自机宽度，可以无限外扩；蓝色把总宽度提升到至少一个自机宽度。盾牌会跟随当前开火方向旋转，只拦截从背后飞来的子弹。
- **移速**：白色 +50%，蓝色 +100%，移速加成上限为 **100%**（即初始移速的 200%）。到达上限后，移速卡会从卡池中移除。
- **修正力度**：初始为 `I`（基础伤害 100%）。每提升一级，自机所有来源的伤害（子弹、激光、环绕脚注、修订光环）+20%；`+1 / +2 / +3` 分别增加对应等级，可重复叠加。
- **注意分散**：第一次选取得到总夹角 60° 的三条弹道（左 30°、中、右 30°）。重复选取时，在现有最大角度外各再加 1 条，即下一次外扩到 ±60°，再下一次到 ±90°。当弹道围满一圈后，相同角度的弹道会合并成一条：不再生成重复子弹/激光，而是把该角度的伤害乘以重叠数量。例如两条弹道重叠时只运算一条，但该弹道伤害变为 200%。
- **攻击方式（激光 / 火箭 / 三叉）**：攻击方式只替换“发射器”，不会清空注意分散、附加弹丸、射速、修正力度、护盾、环绕或光环；三种攻击方式可以互相切换。以普通红卡权重 1 为基准：未获得任何攻击方式时，三种攻击方式卡权重为 **2**；获得任意一种后，剩余攻击方式卡权重降为 **0.25**。
- **激光审阅**：贯穿式光束；基础脉冲速度为普通攻击速度的 **150%**，单束基础伤害为 1，因此单目标基础 DPS 是未拾取激光时的 **150%**。注意分散会同时射出多条激光；**增补弹丸**在激光模式下不再增加单束伤害，而是为每条弹道增加一束平行激光，每束仍为 1 点基础伤害。
- **火箭校对**：符号为深蓝色 `=` 的火箭，弹体会随飞行方向旋转，纵向发射时显示为纵向 `=`；单发直接伤害是基础攻击的 300%，射速降为 50%，命中敌人后产生范围爆炸。注意分散会同时发射多枚扇形火箭，附加弹丸会增加平行火箭。
- **三叉**：红色攻击方式，符号 `三`。每一条弹道都会发射三束夹角 10° 的子弹，单发伤害为基础攻击的 80%；子弹绘制为紫色短横线 `-`，与普通蓝色圆点子弹区分。注意分散产生的每条额外弹道也会各自变成三束。不能重复获得，持有期间卡池不会再次出现三叉，但可以被激光或火箭替换。
- **环绕脚注**：已升级为蓝色稀有度；每颗脚注的尺寸是旧版的 2 倍，轨道半径为旧版的 1.5 倍。每次选取增加 2 颗环绕物，每颗都会撞击敌人并拦截敌方子弹。

### 联动奖励卡

- **死而后生（白）**：每拾取四个修订，直接获得一张白色“修正力度 +1”卡；这张白卡会正常计入白卡数量并触发白日梦。实际效果仍以拾取蓝色血包（修订）计数。
- **愈战愈勇（红）**：每击败一个敌人，攻击速度 +1%。
- **信心爆棚（红）**：每击败一个 Boss，直接获得一张蓝色“注意分散”卡。注意分散会正常计入蓝卡数量并触发蓝海。
- **白日梦（蓝）**：每拥有一张白色奖励卡，修正力度 +1。获得时先按当前已有白卡立即结算一次，之后每获得一张白卡再 +1。
- **蓝海（红）**：每拥有一张蓝色奖励卡，攻击速度 +20%。获得时先按当前已有蓝卡立即结算一次，之后每获得一张蓝卡再 +20%。
- 以上五张联动卡均为**唯一卡**，获得后从卡池移除，不会重复出现。
- 白 / 蓝 / 红卡数量按**实际获得的奖励卡**累计，包括 Boss 掉落、死而后生和信心爆棚直接生成的卡；重开或控制台清空奖励时归零。
- **修订光环**：自机周围持续造成伤害；由于环绕轨道扩大，光环半径也同步扩大，避免两个圆环挤在一起。
- **格式繁多**：红色、唯一性奖励。获得后每次格式奖励从 3 个选项变成 4 个；不能叠加，获得后从卡池移除。
- **急速修改**：蓝色奖励。移动时按当前攻速向移动方向发射两列较小的深棕色额外子弹，两列中心距与自机同宽；基础单发伤害为普通子弹的 25%，并随移速线性提升，达到 200% 移速时每颗为普通子弹的 200%。这些子弹不享受注意分散或增补弹丸加成；获得后移出卡池，不会重复出现。
- **激光**和**火箭**是攻击方式奖励，互斥替换发射器但绝不覆盖其他升级；**修订光环**和**格式繁多**是唯一性奖励。

开局数值已经做过平衡：自机基础射速降低 50%（射击间隔 0.33 秒）、移速降低 20%，所有敌人的初始血量降低 50%。所有升级只在本局有效，重新开始时清空。

## 页面信息与修正力度

- 文章正下方新增一行文章字体的加粗 `修正力度：I` 显示栏；`I` 的数量严格等于伤害等级。
- 初始为 `I`（基础 100% 伤害），每升一级所有自机伤害 +20%。子弹、激光、环绕脚注和修订光环都吃这个倍率。
- 页面上方原本的 `Page 1` 和右下角页码改为 `第 X 关 · 第 Y 波`；每四波为一关，第四波是首领。
- 敌人等级移到文章左下角原 `Working Paper` 的位置，显示为 `敌人 Lv. N`；阅读视图会隐藏这些游戏提示。
- 竞技场边界固定为页面坐标 `left=58 / top=50 / right=1062 / bottom=733`，即背景定位图里的红框；敌机碰撞箱完全进入红框前只执行直线入场，不追击、不开火、不接触；完全进入后才恢复正常 AI，且之后不会离开红框。

## 四种首领与精英标点

- 首领在四种形态中随机轮换，且不会连续重复同一种：
  - **长句**：快速绕行、贴近自机，并从四向和瞄准方向射击。
  - **方括号 `[ ]`**：两只一组同时登场，左括号从左侧、右括号从右侧进入，停留在页面两端，上下两个端口同时向自机方向射击。
  - **邮件符 `@`**：在地图上以固定斜向速度弹跳；碰到荧光笔障碍或页面边缘时，按碰撞轴翻转一个速度分量，形成 90° 转向，类似弹球。每 0.5 秒向随机方向发射一颗子弹。
  - **比较符号 `<`**：移动方式类似长句，绕自机游走；尖端始终指向下一次攻击方向。交替发射瞄准自机的子弹，或先进行约 1.15 秒的明显蓄力，蓄力结束后锁定方向，再延迟约 0.55 秒发射激光。蓄力结束瞬间正在移动的玩家不会被这道激光击中。
- 普通首领只会在本波至少一半小怪已经出现后入场；最终首领不受这条规则影响。
- 首领 Lv.1 基础血量：长句 **18**、方括号 **12**（每只）、邮件符 **20**、比较符号 **20**；四种首领与普通小怪、稀有敌人共用同一套等级成长模型，方括号每只都单独计算。
- 非稀有普通敌人从第二关开始有 **20%** 概率变成**精英形态**：符号、攻击模式和移动逻辑完全不变，只使用明显的亮红色。
- 精英血量是同级普通版本的 **120%**。击杀后 **50%** 概率掉落一个**蓝色句号血包**，血包存在 **7 秒**；自机满血时血包不会跟随，只有受伤后才会被吸向自机并回复 1 格生命。血包碰撞半径同样扩大到贴图大小（14.5），与自机碰撞箱重合即拾取。

## 金色稀有敌人与格式碎片

- 每个波次开始时先做一次 **33%** 的稀有敌人出现判定；第 1 关第 1 波不会出现，第 1 关第 2 波必定出现。
- 判定成功后，在本波 **0 只到半数小怪已经出现** 的区间内随机取一个入场时点，从随机位置入场。
- 终审波同样进行 33% 判定；因为该波没有普通小怪，判定成功时会在开场时点直接出现。
- 金色格式符有独立的金色外观和倒计时圆环，约 12 秒后会从文档中逃走。
- 击破它会掉落 **1 个格式碎片拾取物**，不再直接增加计数。碎片带有金色 `¶` 外观，拾取机制与血包相同，会主动吸向自机；即使满血也能拾取，而且**不会随时间消失**。拾取物的碰撞半径已扩大到文字外圈贴图大小（14.5），只要和自机碰撞箱有重合就会成功拾取。
- 状态栏里有 `格式碎片 0/3` 和三个小方块提示；集满 **3 张**后，会立刻额外打开一次“格式”奖励窗口，相当于多获得一次自机强化机会；这次额外奖励不会替换当前文章。
- 金色格式符不发射子弹，但会在行间快速移动；它的等级也会跟随敌人等级提升。

## 敌人等级

每清空一次 Boss 波，敌人等级 +1。所有普通小怪、稀有敌人、精英和四种普通首领都使用同一套模型：

```text
实际血量 = round((Lv.1 基础血量 + (敌人等级 - 1)) × 等级倍率)
```

等级倍率从 Lv.2–Lv.3 每级 **+10%**，从 Lv.4 开始每级 **+20%**；精英在算完后额外乘 **1.2**。最终 Boss 仍是同级长句 Boss 的 **10 倍**。射速仍每级提升 5%。当前等级显示在文章页面左下角的 `敌人 Lv. N` 中，初始为 Lv.1。关卡结束时不再自动为玩家恢复生命值。

## 终审与 40 波节点

- 每 **40 波**出现一次终审波，只出现最终 Boss“终审修订框”，不再出现普通小怪。
- 最终 Boss 出现前会先震动约 2.4 秒，震动幅度逐渐增大；随后从竞技场正上方缓慢压入。
- 最终 Boss 的碰撞箱可以穿过荧光笔障碍，不会被墙体挡住。
- 最终 Boss 在入场后、第一次出手前处于**无敌**状态，子弹、激光、光环和环绕物都打不掉血；这段时间框内显示“无敌 · 准备中”，且**不显示血条**。
- 无敌结束前约 0.55 秒会发出一次终审咆哮：三层金红冲击波、`吼 / ！ / 审` 文字粒子、巨型“吼——”浮字、屏幕闪光、强烈震动和低频吼声，提示它即将开始攻击。
- 第一次攻击开始后解除无敌，血条才会出现；框内文字与射击节奏同步，每次发射环射或瞄准弹时都会切换一句“我是最终boss”“这一页由我终审”等文字，冲锋不切换。
- 终审修订框的血量是同级常规 Boss 的 **10 倍**；会随机发射环状弹、朝自机瞄准射击，或向自机冲锋。
- 终审期间每 **5 秒**会从页面外侧拉来一只随机小怪，但场上由它召唤的小怪最多 **3 只**。
- 击败终审修订框后先弹出“恭喜全部修订成功 / 是否继续？（保留所有格式）”。
- 最终 Boss 被击败的瞬间，场上所有小怪会立刻一起消灭。
- 随后播放约 1.8 秒的终审爆炸：多重冲击波、金红紫碎片、`✓ / 终 / 审 / ！` 文字粒子、屏幕闪光和强震动，动画结束后才显示通关界面。
- 选择继续后按普通 Boss 结算：完整保留当前格式，打开一次格式三选一，随后换图并进入下一波；这次三选一固定出现 **3 个红色奖励**。
- 第 40、80、120、160 波等每个 40 的倍数都会重复这一流程。

## 六张文章地图

击败 Boss 并选择完格式奖励后，会从以下 6 篇文章中随机抽取一篇（不会连续重复当前篇），重新排版为新的文章地图：

1. `Residual Attention`
2. `Marginal Syntax`
3. `The Quiet Ledger`
4. `Drafting Daylight`
5. `The Office of Small Errors`
6. `After the Cursor`

换图时会同步更新 Word 标题栏文件名、页面标题、摘要、章节标题、作者和词数；荧光笔障碍会切换到该地图的固定布局，玩家会被移到不会卡进障碍的位置。

每张地图的障碍都有独立的“笔迹档案”：

- `Residual Attention`：黄色，6 道固定高亮。
- `Marginal Syntax`：绿色，13 道固定短高亮。
- `The Quiet Ledger`：蓝色，11 道固定高亮。
- `Drafting Daylight`：橙色，4 道固定高亮。
- `The Office of Small Errors`：紫色，16 道固定高亮。
- `After the Cursor`：青色，18 道固定高亮。

因此不同地图的障碍数量、长度、分布栏位和颜色都有明显区别。

## 测试控制台

- 按 **`F2`** 打开或关闭测试控制台；也可以用 `?cheat=1` 在开始游戏后自动展开，避免控制台挡住开始按钮。
- **无敌模式**：开启后自机不受伤，并把生命补满。
- **关卡跳转**：选择第 1–40 关，可跳到该关开始波，或直接跳到该关关底 Boss 波；跳关会同步敌人等级并清空当前弹幕。
- **攻击方式**：下拉菜单选择默认 / 激光 / 火箭 / 三叉，立即切换。
- **移速 / 攻速**：实时显示当前倍率，不再提供攻速和修订力度下拉菜单。
- **奖励卡按钮**：每种奖励卡对应一个按钮，点一次立刻获得一张，可重复叠加；按钮按稀有度着色，悬停可看效果说明。
- **清除全部已获得奖励卡**：把射速、移速、护盾、弹丸、分散、攻击方式、环绕、光环和修订力度全部恢复到初始状态。

## 小提示

- 指针旁的四段圆形加载条就是生命值，剩几段就能再承受几次碰撞或子弹。
- 连续击杀会触发词数加成，状态栏的词数会像 Word 统计一样缓慢增长。
- 每轮清理完所有标点后进入下一轮，每四轮会出现首领。首领在长句、方括号二重奏和弹跳邮件符 `@` 之间随机轮换；长句攻击频率是旧版的 70%，移动更快、变向更频繁，会主动绕行寻找自机；邮件符每 0.5 秒随机发射一颗子弹。
- 点击功能区右下角的收起按钮，可以隐藏功能区，把页面放到最大。
- 按 `B` 进入阅读视图后，工具栏、标点、指针和生命值全部消失，只剩文档本身；再按一次 `B` 返回。
